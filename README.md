## Built for people who build

OQVAR gives architects, engineers, contractors, and project teams a faster way to work with complex plans. Ask a question in plain language, get a precise answer, and see the exact drawing or model elements behind it.

No black box. No hunting through sheets. Just answers with proof.

## What you can do

- **Ask naturally** — Find rooms, dimensions, quantities, fixtures, schedules, and model data in the language your team uses.
- **Verify every answer** — See the source objects highlighted directly on the original 2D sheet and linked 3D model.
- **Work across formats** — Bring together CAD drawings, PDFs, scanned plans, and IFC/BIM models in one workspace.
- **Understand buildings in 3D** — Explore plans as a navigable model and move seamlessly between the model and its source drawing.
- **Move with confidence** — OQVAR computes answers from drawing geometry and BIM data wherever possible, so teams can check decisions in seconds.

## From question to proof

1. Open a drawing or model.
2. Ask OQVAR a question.
3. Review the answer and its highlighted evidence.
4. Share the decision with confidence.

## Get started

```bash
uv sync
uv run uvicorn stoa_qa.api:app --port 8765
```

Open [http://localhost:8765](http://localhost:8765) to launch OQVAR.
